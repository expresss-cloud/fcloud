Click a header to sort A–Z or Z–A, Shift-click to add a second sort. Use the boxes under each header to filter that column (numbers accept >50, <=10 or 5-20).

Real data: export the FMCSA Company Census File (data.transportation.gov) for one or a few states as CSV or Excel and import it. Recognized columns include DOT_NUMBER, LEGAL_NAME, PHY_STATE, PHY_CITY, PHY_ZIP, NBR_POWER_UNIT, DRIVER_TOTAL, HM_FLAG and an inspections column (insp_total). Add LATITUDE and LONGITUDE columns for exact dots; without them dots are placed approximately inside the state by ZIP. Files stay in your browser.
